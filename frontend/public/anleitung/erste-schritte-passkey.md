Mit einem Passkey melden Sie sich im {name} ohne Passwort und ohne Einmalcode an: Ihr Gerät (iPhone, Mac, Sicherheitsschlüssel) prüft mit Fingerabdruck, Gesicht oder PIN, dass Sie es sind. Der Passkey ist freiwillig. Wer keinen einrichtet, meldet sich weiter mit Passwort und Code aus der Authenticator-App an.

## Passkey einrichten
1. Melden Sie sich wie gewohnt mit Passwort und Code an.
2. Ab 600 px wählen Sie oben rechts «Passkey einrichten» (Schlüssel-Symbol, neben «Hilfe»); unter 600 px wählen Sie dort das Schlüssel-Symbol. Die Kontoverwaltung der Anmeldung öffnet sich in einem neuen Tab; das Archiv bleibt in Ihrem bisherigen Tab offen.
3. Wählen Sie in der Kontoverwaltung den Bereich zur Anmeldung und dort «Passkey einrichten».
4. Geben Sie dem Passkey einen Namen, zum Beispiel «iPhone», und bestätigen Sie mit Fingerabdruck, Gesicht oder PIN Ihres Geräts.

Sie können mehrere Passkeys einrichten, zum Beispiel für iPhone und Mac, und in der Kontoverwaltung jeden wieder entfernen. Den Knopf «Passkey einrichten» sehen alle angemeldeten Benutzer; ihn zu verwenden ist freiwillig. Das Archiv speichert nie Fingerabdruck oder Gesicht; sie bleiben auf Ihrem Gerät.

## Mit Passkey anmelden
1. Wählen Sie auf der Startseite «Anmelden».
2. Wählen Sie auf der Anmeldeseite im Feld «Benutzername» den vorgeschlagenen Passkey oder die Anmeldung mit Passkey.
3. Bestätigen Sie mit Fingerabdruck, Gesicht oder PIN. Passwort und Code sind dann nicht nötig.

Der Passkey genügt auch, wenn das Archiv bei einer wichtigen Änderung eine erneute Anmeldung verlangt. Mit einem eingerichteten Passkey gehen Passwort und Code nicht verloren: Passwort und Authenticator-App bleiben als Rückfall gültig.

## Gerät verloren oder Passkey geht nicht mehr
Melden Sie sich mit Passwort und Code an und entfernen Sie den Passkey in der Kontoverwaltung (oben rechts «Passkey einrichten»). Haben Sie auch Passwort oder Authenticator-App nicht mehr, wenden Sie sich an eine Inhaberin oder einen Inhaber Ihres Mandanten. Sie oder er setzt Ihren Zugang zurück und löscht dabei auf Wunsch Ihre Passkeys. Danach melden Sie sich mit Passwort und Code neu an und richten bei Bedarf einen neuen Passkey ein.

> **Hinweis:** Ein Passkey gehört zur Internetadresse des Archivs. Wechselt das Archiv auf eine neue Adresse, gelten die bisherigen Passkeys nicht mehr. Melden Sie sich dann mit Passwort und Code an und richten Sie die Passkeys neu ein.
