Als Inhaber öffnen Sie in der Seitenleiste «Chat-Auswertung». Die Seite zeigt nur Bewertungen Ihres Mandanten.

## Auswertung lesen
Wählen Sie einen Zeitraum von höchstens 12 Monaten. Die Auswertung zeigt Anzahl und Durchschnitt der Bewertungen,
die Verteilung nach Sternen, freiwillig angegebene Gründe und bis zu 100 niedrig bewertete Antworten. Fragen können
Personendaten enthalten; behandeln Sie die angezeigten Inhalte vertraulich.

## ZIP-Export
1. Wählen Sie «Export vorbereiten».
2. Prüfen Sie Zeitraum und Sternebereich.
3. Lassen Sie «Bekannte Personendaten im Export schwärzen» aktiviert. Das ist die Voreinstellung.
4. Wählen Sie «ZIP herunterladen». Das ZIP enthält die Daten, das Schema und eine README-Datei.

Ein ungeschwärzter Export enthält möglicherweise Personendaten. Wählen Sie diese Möglichkeit nur, wenn Sie die Datei
sicher aufbewahren können; die Anwendung verlangt dafür eine ausdrückliche Bestätigung.

Für den Export ist eine frische Anmeldung nötig. Wenn Sie dazu aufgefordert werden, melden Sie sich erneut an und
geben Sie danach Zeitraum und Sternebereich nochmals ein. Die Filter werden nicht im Browser gespeichert.
