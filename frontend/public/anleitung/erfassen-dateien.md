Digitale Belege wie PDF-Rechnungen oder eingescannte Dokumente laden Sie unter «Erfassen» im Teil «Dateien hochladen» hoch, am Computer oder am Handy. Erlaubt sind PDF, JPEG, PNG, HEIC/HEIF und TIFF bis 50 MB pro Datei, auch mehrere auf einmal. Das Hochladen von Dateien braucht eine Anmeldung und eine Verbindung.

## So laden Sie Dateien hoch

1. Ziehen Sie die Dateien auf das Feld «Dateien hierher ziehen» oder wählen Sie «Dateien auswählen».
2. Prüfen Sie die Liste «Ausgewählte Dateien». Mit den Pfeilen ändern Sie die Reihenfolge, mit dem Kreuz entfernen Sie eine Datei.
3. Wählen Sie «Hochladen». Während der Übertragung sehen Sie den Fortschritt in Prozent.
4. Unter «Ergebnis je Datei» steht für jede Datei, was geschehen ist.
5. Mit «Weitere Dateien erfassen» beginnen Sie von vorn.

Jede Datei wird ein eigenes Dokument, ausser Sie fassen Bilder zusammen.

## Mehrere Bilder als ein Dokument

Gehören mehrere Bilder zusammen, zum Beispiel die fotografierten Seiten eines Vertrags:

1. Wählen Sie die Bilder aus und bringen Sie sie mit den Pfeilen in die richtige Reihenfolge.
2. Kreuzen Sie «Als ein Dokument zusammenfassen (Seiten in der Reihenfolge der Liste)» an. Das ist ab zwei Bildern möglich (JPEG, PNG, HEIC/HEIF, TIFF), nicht mit PDF.
3. Wählen Sie «Hochladen».

## Ergebnis je Datei

- «Angenommen, wird verarbeitet»: Das Archiv liest die Datei. Danach erscheint sie im [Eingangskorb](#eingangskorb).
- «bereits vorhanden»: Genau diese Datei ist schon im Archiv; es entsteht kein zweites Dokument. Dürfen Sie das vorhandene Dokument sehen, öffnen Sie es mit «Vorhandenes Dokument öffnen».
- «Abgelehnt»: Die Datei wurde nicht angenommen; dahinter steht der Grund. Die übrigen Dateien sind davon nicht betroffen.

## Häufige Meldungen

- «Dieser Dateityp wird nicht unterstützt. Erlaubt sind PDF, JPEG, PNG, HEIC/HEIF und TIFF.» Das Archiv erkennt den Typ am Inhalt, nicht an der Endung. Speichern Sie die Datei als PDF und laden Sie sie erneut hoch.
- «Die Datei ist grösser als 50 MB. Bitte verkleinern oder aufteilen.»
- «Die Datei ist leer oder beschädigt. Bitte prüfen und erneut hochladen.»
- «Die Dateien sind zusammen zu gross für einen Upload. Bitte in mehreren Schritten mit weniger Dateien hochladen.»
- «Keine Verbindung zum Archiv. Bitte prüfen Sie die Verbindung und versuchen Sie es erneut.» Dateien warten nicht in der Warteschlange. Wählen Sie «Erneut hochladen», sobald die Verbindung zurück ist.
- «Ihre Sitzung ist abgelaufen. Bitte melden Sie sich erneut an und laden Sie die Dateien neu hoch.»
