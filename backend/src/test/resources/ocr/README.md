# Testdateien OCR

- `foto.heic`: synthetisch, keine echten Daten. Mit Java2D gezeichnet (Text «Testbeleg synthetisch», «Muster
  Handy-Foto HEIC», «Quittung Nummer 4711», «Betrag CHF 42.00») und auf macOS mit `sips -s format heic` gewandelt.

Alle übrigen Testdateien (Fotos, Mehrseiten-PDF, PDF mit Textebene, signiertes und verschlüsseltes PDF) erzeugt
`OcrTestdateien` zur Laufzeit.
