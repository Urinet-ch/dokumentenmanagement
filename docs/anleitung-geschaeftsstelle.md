# Anleitung für die Geschäftsstelle

## Anmelden

1. Öffnen Sie das Archiv über den bereitgestellten Link: [Link zum Archiv eintragen].
2. Wählen Sie «Anmelden» und melden Sie sich mit Ihrem Benutzerkonto an.
3. Im Menü finden Sie «Erfassen», «Eingangskorb» und «Suche».

Wenn Ihrem Benutzer kein Mandant oder keine Rolle zugeordnet ist, erscheint:
«Ihrem Benutzer ist kein Mandant oder keine Rolle im Archiv zugeordnet. Bitte wenden Sie sich an den Inhaber.»
Wenden Sie sich an [Kontaktstelle Geschäftsstelle einsetzen].

## Dokumente hochladen

### Am Computer

1. Öffnen Sie «Erfassen».
2. Ziehen Sie Dateien auf «Dateien hierher ziehen» oder wählen Sie «Dateien auswählen».
3. Erlaubt sind PDF, JPEG, PNG, HEIC/HEIF und TIFF. Eine Datei darf höchstens 50 MB gross sein.
4. Mehrere Dateien werden einzeln hochgeladen. Ab zwei Bildern können Sie «Als ein Dokument zusammenfassen (Seiten in der Reihenfolge der Liste)» wählen. Ordnen Sie die Seiten vorher mit den Pfeilen.
5. Wählen Sie «Hochladen». Warten Sie auf das Ergebnis je Datei.

«Angenommen, wird verarbeitet» bedeutet, dass das Archiv die Datei erhalten hat. Sie erscheint danach zur Prüfung im «Eingangskorb».

[Bildschirmfoto: Dateiauswahl, Reihenfolge und «Hochladen»]

### Am Handy

1. Öffnen Sie «Erfassen». Wenn die Kamera verfügbar ist, wählen Sie «Kamera öffnen».
2. Nehmen Sie jede Seite mit «Seite aufnehmen» auf. Die Aufnahmen ergeben zusammen ein Dokument.
3. Prüfen Sie die Seiten und wählen Sie «Erfassung abschliessen».
4. Wenn keine Kamera verfügbar ist, wählen Sie «Foto aufnehmen oder auswählen».

Ohne Verbindung zeigt das Archiv: «Erfassung gespeichert. Sie wird hochgeladen, sobald eine Verbindung besteht.» Die Erfassung wartet dann auf diesem Gerät.

## Pflichtangaben prüfen

Der Titel ist bei jeder Dokumentart Pflicht. Zusätzlich verlangt das Seed:

| Dokumentart | Pflichtangaben zusätzlich zum Titel |
| --- | --- |
| Bulletin | Reihe, Ausgabe-Nr., Erscheinungsjahr, Fachgebiet, Verband |
| Jahresbericht | Erscheinungsjahr, Verband |
| Merkblatt | Verband |
| Norm oder Richtlinie | Verband |
| Vorstandsprotokoll | Verband |
| Formular | Verband |
| Sonstiges | Verband |

Beim Bulletin sind die Fachgebiete «Bad», «Eis», «Technik», «Recht» und «Allgemein». Als Verbände sind VHF und GSK vorgesehen; mindestens einer muss gesetzt sein.

**Wichtig:** Das Pflichtfeld «Verband» ist derzeit nicht in der Eingabemaske vorhanden. Wenn die Bestätigung meldet «Bitte ergänzen: Verband.» und kein Eingabefeld dafür angeboten wird, können Sie das Dokument nicht fertig bestätigen. Tragen Sie keinen geratenen Wert ein. Wenden Sie sich an [Kontaktstelle Geschäftsstelle einsetzen].

## Eingangskorb prüfen und bestätigen

1. Öffnen Sie «Eingangskorb». Neue Dokumente stehen zuerst.
2. Öffnen Sie «Angaben ändern» und prüfen Sie Art, Titel und angezeigte Angaben.
3. Prüfen Sie jeden mit «bitte prüfen» markierten KI-Vorschlag. Korrigieren Sie falsche Angaben.
4. Wählen Sie die passende «Zugriffsstufe»:

| Stufe | Bedeutung |
| --- | --- |
| Öffentlich | Für alle Besucher der Webseite |
| Mitglieder | Für Mitglieder, einschliesslich Vorstand |
| Vorstand | Nur für den Vorstand |

Die Voreinstellung ist «Mitglieder». Bei «Vorstandsprotokoll» ist sie «Vorstand». Die Zugriffsstufe wird manuell gewählt.
5. Wählen Sie «Bestätigen». Das Archiv meldet «[Titel]» bestätigt, wird archiviert. Warten Sie, bis die Archivierung abgeschlossen ist.

## Veröffentlichen oder zurückziehen

1. Suchen Sie das archivierte Dokument über «Suche» und öffnen Sie es.
2. Wählen Sie «Metadaten bearbeiten».
3. Setzen Sie «Veröffentlicht» auf «Ja», um es für die Web-Schnittstelle freizugeben. Zum Zurückziehen setzen Sie das Feld auf «Nein».
4. Geben Sie bei «Grund der Änderung» einen kurzen Grund ein und wählen Sie «Änderungen speichern».

Die Web-Schnittstelle liefert nur archivierte Dokumente mit «Veröffentlicht» = «Ja» und Vertraulichkeit «Normal». Zusätzlich muss die Zugriffsstufe für die Webseite zugelassen sein. Ein «Vorstandsprotokoll» hat die Vertraulichkeit «Intern» und wird deshalb nicht über die Web-Schnittstelle ausgegeben.

Nach dem Zurückziehen liefert die Schnittstelle das Dokument nicht mehr aus. Wann eine Webseite die Änderung abruft und anzeigt, ist nicht festgelegt. Eine bestimmte Aktualisierungszeit kann daher nicht zugesichert werden.

## Wenn etwas nicht klappt

- **«bereits vorhanden»:** Die Datei ist schon erfasst. Wenn «Vorhandenes Dokument öffnen» erscheint, öffnen Sie dieses Dokument. Laden Sie keine zweite Kopie hoch. Wenn kein Link erscheint, wenden Sie sich an [Kontaktstelle Geschäftsstelle einsetzen].
- **Datei nicht lesbar:** Bei «Die Datei ist leer oder beschädigt. Bitte prüfen und erneut hochladen.» prüfen Sie die Datei und erstellen Sie einen neuen Scan oder Export. Laden Sie die neue Datei hoch.
- **Dateityp oder Grösse:** Bei «Dieser Dateityp wird nicht unterstützt» verwenden Sie PDF, JPEG, PNG, HEIC/HEIF oder TIFF. Bei «Die Datei ist grösser als 50 MB. Bitte verkleinern oder aufteilen.» verkleinern oder teilen Sie die Datei.
- **«Für diese Aktion fehlt Ihnen das Recht.»:** Prüfen Sie, ob Sie mit dem richtigen Benutzer angemeldet sind. Wenden Sie sich an [Kontaktstelle Geschäftsstelle einsetzen], wenn die Meldung bleibt.
- **Pflichtfeld «Verband» fehlt:** Die aktuelle Eingabemaske bietet dieses Feld nicht an. Brechen Sie die Bestätigung ab und melden Sie es an [Kontaktstelle Geschäftsstelle einsetzen].
